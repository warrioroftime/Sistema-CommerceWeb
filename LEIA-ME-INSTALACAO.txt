PRÉ-REQUISITOS (instale antes de rodar o instalador):
──────────────────────────────────────────────────────
 1. Windows 10 ou superior (64 bits)
 2. SQL Server Express (gratuito):
    https://www.microsoft.com/pt-br/sql-server/sql-server-downloads
    → Escolha "Express" → Instale com as opções padrão
    → Anote o nome da instância (ex: .\SQLEXPRESS)
 3. SQL Server Management Studio (opcional, para gerenciar o banco):
    https://aka.ms/ssmsfullsetup

OBS: O Node.js será instalado automaticamente pelo instalador
     caso não esteja presente na máquina.

COMO INSTALAR:
──────────────────────────────────────────────────────
 1. Copie esta pasta inteira para a máquina destino
    (ou clone o repositório: git clone https://github.com/warrioroftime/Sistema-SAS.git)

 2. Clique com o botão direito em "instalar.ps1"
    → Executar com o PowerShell
    (Se aparecer erro de política: abra o PowerShell como Administrador e execute:
     powershell -ExecutionPolicy Bypass -File instalar.ps1)

 3. Siga as instruções na tela:
    - Confirme o diretório de instalação (padrão: C:\GestorFlex)
    - Informe os dados de conexão do SQL Server
    - Aguarde a instalação das dependências

 4. Ao final, dois atalhos serão criados na Área de Trabalho:
    • GestorFlex - Iniciar  → inicia os servidores e abre o navegador
    • GestorFlex - Parar    → encerra os servidores

COMO USAR APÓS INSTALAÇÃO:
──────────────────────────────────────────────────────
 • Duplo clique em "GestorFlex - Iniciar" na Área de Trabalho
 • O sistema abrirá automaticamente em http://localhost:5500
 • Para parar: duplo clique em "GestorFlex - Parar"

ARQUIVOS DA INSTALAÇÃO:
──────────────────────────────────────────────────────
 instalar.ps1      → Execute para instalar em uma nova máquina
 iniciar.bat       → Inicia os servidores manualmente
 parar.bat         → Para os servidores
 gestorflex/
   backend/        → Servidor Node.js (porta 3001)
   frontend/       → Interface web (porta 5500)

SUPORTE / PROBLEMAS COMUNS:
──────────────────────────────────────────────────────
 ❌ "Não consigo conectar ao SQL Server"
    → Verifique se o serviço SQL Server está iniciado
    → Painel de Controle → Serviços → SQL Server (SQLEXPRESS)
    → Certifique-se que o login "sa" está habilitado no SQL Server

 ❌ "Porta 3001 já está em uso"
    → Execute parar.bat e tente novamente

 ❌ "node não é reconhecido como comando"
    → Instale o Node.js em https://nodejs.org (versão LTS)
    → Reinicie o computador após instalar

 ❌ Erro de política do PowerShell
    → Abra PowerShell como Administrador e execute:
      Set-ExecutionPolicy RemoteSigned -Scope CurrentUser
