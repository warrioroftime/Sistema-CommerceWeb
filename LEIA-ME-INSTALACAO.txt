O INSTALADOR CUIDA DE TUDO AUTOMATICAMENTE:
──────────────────────────────────────────────────────
  ✔ Node.js LTS           → instalado via winget se necessário
  ✔ SQL Server 2022 Express → baixado e instalado se necessário (~300 MB)
  ✔ Banco de dados GestorFlex → criado e configurado
  ✔ Dependências Node.js  → npm install automático
  ✔ Atalhos na Área de Trabalho → criados ao final

PRÉ-REQUISITOS MÍNIMOS:
──────────────────────────────────────────────────────
  • Windows 10 ou superior (64 bits)
  • Conexão com a internet (apenas durante a instalação)
  • Executar como Administrador (recomendado)

COMO INSTALAR:
──────────────────────────────────────────────────────
  1. Copie esta pasta para a máquina destino
     (ou clone: git clone https://github.com/warrioroftime/Sistema-SAS.git)

  2. Clique com botão direito em "instalar.ps1"
     → "Executar com o PowerShell"

     Se aparecer erro de política de execução:
     → Abra o PowerShell como Administrador e execute:
       powershell -ExecutionPolicy Bypass -File instalar.ps1

  3. Siga as instruções na tela:
     - Confirme o diretório (padrão: C:\GestorFlex)
     - Caso o SQL Server não esteja instalado, defina uma senha
       para o administrador do banco (SA)
     - Aguarde a instalação (pode levar 10-20 min na primeira vez)

  4. Ao final, dois atalhos são criados na Área de Trabalho:
     • GestorFlex - Iniciar → abre o sistema no navegador
     • GestorFlex - Parar   → encerra os servidores

COMO USAR APÓS INSTALAÇÃO:
──────────────────────────────────────────────────────
  • Duplo clique em "GestorFlex - Iniciar" na Área de Trabalho
  • O sistema abre em http://localhost:5500
  • Para encerrar: duplo clique em "GestorFlex - Parar"

ARQUIVOS:
──────────────────────────────────────────────────────
  instalar.ps1            → Instalador principal
  iniciar.bat             → Inicia os servidores
  parar.bat               → Para os servidores
  LEIA-ME-INSTALACAO.txt  → Este arquivo
  gestorflex/
    backend/              → Servidor Node.js (porta 3001)
    frontend/             → Interface web (porta 5500)

PROBLEMAS COMUNS:
──────────────────────────────────────────────────────
  ❌ Erro de política do PowerShell
     → Execute: powershell -ExecutionPolicy Bypass -File instalar.ps1

  ❌ "winget não reconhecido"
     → Atualize o Windows ou instale manualmente:
       Node.js: https://nodejs.org (versão LTS)
       SQL Server Express: https://www.microsoft.com/pt-br/sql-server/sql-server-downloads

  ❌ Falha no download do SQL Server
     → Verifique a conexão com a internet
     → Instale manualmente o SQL Server Express e re-execute instalar.ps1

  ❌ "Porta 3001 ou 5500 já está em uso"
     → Execute parar.bat e tente novamente

  ❌ SQL Server não conecta após instalação
     → Abra "Serviços" do Windows → inicie "SQL Server (SQLEXPRESS)"
     → Certifique-se que o login SA está habilitado
